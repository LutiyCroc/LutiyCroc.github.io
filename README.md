# Полиночка и маленькое чудо 🎂

Интерактивный сайт-поздравление с днём рождения — нежная сказка с милым котиком, сердечками, подарками и **интерактивным планером путешествия по Санкт-Петербургу**.

## 🌟 Особенности

- **6 интерактивных экранов**: от приветствия до финального письма
- **Анимированный котик** в разных позах (SVG-иллюстрации)
- **Сбор сердечек** с комплиментами
- **Три подарка** с индивидуальными посланиями
- **🆕 Интерактивный планер Санкт-Петербурга**:
  - 7 мест для посещения с реальными ссылками
  - Выбор мест с фильтрами (Еда, Культура, Выбранное)
  - Составление маршрута с возможностью изменения порядка
  - Добавление заметок и планов для каждого места
  - Выбор настроения свидания
  - Кнопка "Удиви меня" для случайного выбора
  - Итоговая открытка с возможностью копирования и печати
  - Сохранение данных в localStorage
- **Финальное письмо** с персональным поздравлением
- **Продвинутые анимации**: частицы, переходы, мягкие эффекты
- **Полностью адаптивный дизайн**: работает на телефонах и планшетах
- **Доступность**: поддержка клавиатурной навигации и prefers-reduced-motion
- **Без зависимостей**: чистый HTML, CSS, JavaScript

## 🚀 Быстрый запуск

### Вариант 1: Прямое открытие (самый простой)

Просто откройте файл `index.html` в любом современном браузере:
- Дважды кликните по `index.html`
- Или перетащите файл в окно браузера

### Вариант 2: Локальный сервер (рекомендуется)

Если у вас установлен Python:

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

Затем откройте `http://localhost:8000` в браузере.

Если у вас установлен Node.js:

```bash
npx serve
```

## 📝 Персонализация

Все тексты редактируются в файле `js/content.js`:

```javascript
const content = {
    intro: {
        title: "Полиночка, сегодня для тебя кое-то особенное!",
        catSpeech: "Мяу! Я приготовил маленькое приключение. Пойдём?",
        buttonText: "Начать приключение ♡"
    },
    // ... остальные секции
    final: {
        message: `
            Дорогая Полиночка!
            
            [Ваше личное поздравление здесь]
        `,
        signature: "Обнимаю тебя крепко-крепко. ♡"
    }
};
```

### Замена изображений

Все иллюстрации котика находятся в папке `assets/images/`:
- `cat-main.svg` — котик на стартовом экране
- `cat-happy.svg` — радостный котик
- `cat-travel.svg` — котик с чемоданом (пасхалка)
- `cat-final.svg` — котик с цветами (финал)

Вы можете заменить их на свои PNG или SVG изображения. Измените пути в `js/content.js`:

```javascript
assets: {
    mainCat: "assets/images/your-cat-main.png",
    happyCat: "assets/images/your-cat-happy.png",
    // ...
}
```

## 🎮 Как играть

1. **Стартовый экран**: нажмите «Начать приключение ♡»
2. **Сбор сердечек**: кликните на все три сердечка, чтобы собрать комплименты
3. **Подарки**: откройте три коробочки в любом порядке
4. **🆕 Планер Петербурга**: найдите лапку в правом нижнем углу и откройте интерактивный планер:
   - Выберите места для посещения (7 локаций с реальными ссылками)
   - Составьте маршрут с заметками
   - Выберите настроение свидания
   - Создайте итоговую открытку
5. **Финал**: откройте конверт и прочитайте личное поздравление

## 🌐 Публикация на GitHub Pages

### Шаг 1: Создайте репозиторий

```bash
git init
git add .
git commit -m "Initial commit: birthday card for Polinochka"
```

Создайте новый репозиторий на GitHub и подключите:

```bash
git remote add origin https://github.com/your-username/your-repo.git
git branch -M main
git push -u origin main
```

### Шаг 2: Включите GitHub Pages

1. Откройте репозиторий на GitHub
2. Перейдите в Settings → Pages
3. В разделе Source выберите:
   - Branch: `main`
   - Folder: `/ (root)`
4. Нажмите Save

Через несколько минут сайт будет доступен по адресу:
`https://your-username.github.io/your-repo/`

### Публикация из подпапки

Если вы публикуете проект из подпапки существующего репозитория:

1. В настройках Pages выберите Branch и папку (например, `/pages`)
2. В HTML убедитесь, что все пути относительные (уже настроено)

## 🐛 Поиск проблем

Если что-то не работает:

1. **Проверьте консоль браузера** (F12 → Console) на наличие ошибок
2. **Убедитесь**, что все файлы (CSS, JS, SVG) находятся в правильных папках
3. **Проверьте**, что браузер поддерживает ES6 (современные браузеры)
4. **Попробуйте** открыть через локальный сервер вместо прямого доступа к файлу
